⚙ Nastavení e-mailu
Zadejte váš Brevo API klíč a odesílací e-mail. Údaje jsou uloženy v databázi a fungují na všech zařízeních.
Jak získat API klíč
  1. Přihlaste se na brevo.com
  2. Klikněte na vaše jméno vpravo nahoře → SMTP & API
  3. Záložka API Keys → klikněte na ikonku oka nebo Copy
  4. Vložte klíč do pole výše a uložte
